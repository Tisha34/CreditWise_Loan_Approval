# CreditWise Loan Approval Prediction Using Machine Learning Algorithms

# Problem Statement:
SecureTrust Bank receives hundreds of loan applications daily through online and branch channels. Traditional manual verification methods are time-consuming, inconsistent, and prone to human bias, leading to rejection of genuine applicants and approval of high-risk customers.

This project aims to build an Intelligent Loan Approval Prediction System using Machine Learning algorithms to automate loan approval decisions based on applicant financial, demographic, and credit-related information.


# Project Workflow:
Performed Exploratory Data Analysis (EDA) to identify loan approval patterns and financial trends

Cleaned and preprocessed data by handling missing values and outliers

Applied Feature Engineering using Label Encoding, One Hot Encoding, and StandardScaler

Built and trained multiple Machine Learning classification models including Logistic Regression, KNN, and Gaussian Naive Bayes

Evaluated model performance using Accuracy, Precision, Recall, F1 Score, and Confusion Matrix

Compared all models and selected Logistic Regression as the best-performing algorithm with 89% accuracy

Generated business insights using correlation analysis, visualizations, and model predictions to support better loan approval decisions


# Tech Stack:
Python

Pandas, NumPy

Matplotlib, Seaborn

Scikit-learn

Jupyter Notebook


# Results & Business Impact:
1.Achieved 89% accuracy using Logistic Regression, making it the best-performing model for loan approval prediction.

2.Identified Credit Score, Applicant Income, and DTI Ratio as the most important factors influencing loan approval decisions through EDA and correlation analysis.

3.Model training revealed that applicants with higher credit scores and stable income had significantly higher approval probability, improving customer risk assessment.

4.Automated loan prediction can help SecureTrust Bank reduce manual verification time, improve operational efficiency, and speed up approval decisions.

5.The ML model enables more accurate and unbiased lending decisions, helping the company reduce financial risk and improve overall business profitability.
